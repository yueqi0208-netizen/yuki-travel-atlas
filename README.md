# Yuki 的旅行足迹

一个适合手机浏览的单页旅行地图。第一版记录 2026 年 6 月西班牙行程中的六座城市。点击地图上的城市或下方列表，查看当时记下的地点。

## 本地打开

直接打开 `index.html` 即可。网站没有账号、服务器或第三方数据依赖。

## 怎样修改内容

在 `index.html` 底部找到 `const cities = [...]`。每座城市的 `name`、`en`、`places` 是显示的内容；`x`、`y` 是地图位置。地图目前是路线示意。

## GitHub 练习路线

1. 把这份项目放进自己的 GitHub Repository，保留第一次 Commit。
2. 建立 Issue：为每座城市补充自己的照片和一句回忆。
3. 在独立 Branch 上完成其中一座城市，通过 Pull Request 审核后合并。
4. 再做筛选、搜索或新旅程。

请注意：此版本作为私人预览发布；内容和照片若以后要放到公开的 GitHub 仓库，先确认哪些旅行细节愿意公开。
